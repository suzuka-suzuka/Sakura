# Sakura Plugin

Sakura Plugin 是 Sakura Bot 的综合功能插件，提供 AI 对话、图片生成、Pixiv、搜图、表情包、关键词回复、经济系统、钓鱼玩法、群管理、提醒、睡眠记录、自动推送等功能。

插件配置由 `configSchema.js` 定义，运行时配置保存在：

```text
config/sakura-plugin/*.yaml
```

推荐通过 Sakura 的 Web 配置面板编辑配置。

## 环境要求

在框架环境之外，本插件还需要以下能力：

- Node.js 20 或更高版本。
- pnpm 9 或更高版本。
- Redis，经济、上下文、定时任务、订阅等功能需要使用。
- Chrome / Chromium，菜单、签到、画像、表情包列表等截图渲染依赖 Puppeteer。
- 可选：Python，用于部分 MCP 扩展。
- 可选：AI、Pixiv、Grok、NovelAI、VoxCPM 等外部服务账号或 API Key。

## 安装

Sakura Plugin 随 Sakura 主仓库一起发布，不再作为独立 Git 仓库安装。只需要在 Sakura 根目录统一安装依赖：

```bash
cd Sakura
pnpm install
```

插件继续保留自己的 `package.json` 作为依赖边界，所有依赖版本统一记录在 Sakura 根目录的 `pnpm-lock.yaml` 中。

## 启动

插件由 Sakura 框架自动加载。启动框架即可：

```bash
cd Sakura
pnpm dev
```

生产环境：

```bash
pnpm start
pnpm log
```

启动后访问配置面板：

```text
http://localhost:3457
```

登录密码由根目录 `config/config.yaml` 的 `web.password` 决定。

## 配置方式

插件配置目录：

```text
config/sakura-plugin/
```

常用配置文件：

- `bot.yaml`：机器人名称等基础信息。
- `Providers.yaml`：AI 供应商、接口协议、端点和 Key 池。
- `Routes.yaml`：逻辑模型路由、供应商目标和调度策略。
- `ImageChannels.yaml`：生图渠道，包括 Gemini 图片和 OpenAI 图片。
- `AI.yaml`：AI 对话、工具组、上下文、Markdown 处理等设置。
- `roles.yaml`：AI 角色和人设。
- `EditImage.yaml`：图片编辑触发词和生图渠道选择。
- `economy.yaml`：经济系统、启用群、指令消耗价格。
- `pixiv.yaml`：Pixiv cookie、refresh token、订阅推送。
- `nai.yaml`：NovelAI 绘图 token、模型和负面提示词。
- `VoxCPMVoice.yaml`：语音角色和默认语音角色。
- `mimic.yaml`：拟态回复配置。
- `SearchImage.yaml`：搜图渠道和返回数量。
- `poke.yaml`、`repeat.yaml`、`recall.yaml`：戳一戳、复读、防撤回。
- `60sNews.yaml`、`teatime.yaml`、`cool.yaml`：定时和自动推送。

配置文件会由 Web 面板按 `configSchema.js` 自动生成和校验，不建议手写大段 YAML。

## 必填配置建议

### AI 对话

1. 在 `Providers` 中配置供应商端点和至少一个凭据。
2. 在 `Routes` 中配置逻辑模型路由和供应商目标。
3. 在 `roles` 中配置角色。
4. 在 `AI.profiles` 中配置角色触发前缀列表、角色名和模型路由。
5. 群内发送任一角色前缀加内容即可触发对话；多个前缀同时匹配时使用最长前缀。

路由和凭据均支持 `round_robin`、`weighted_round_robin`、`priority`、`priority_weighted`。同一个逻辑路由可以配置多个使用相同模型名的供应商目标。

生成参数放在路由和目标层：路由的 `temperature`、`topP`、`reasoningLevel` 是统一默认值；目标可通过 `temperatureOverride`、`topPOverride` 覆盖采样参数，并使用 `openaiReasoningEffort` 或 `geminiThinkingLevel` / `geminiThinkingBudget` 设置供应商原生思考参数。Provider 只管理连接和凭据，不承载生成参数。

- `temperature` / `topP` 为 `-1` 时不发送，使用模型默认值。
- `reasoningLevel: off` 会映射为 OpenAI `none`、Gemini `thinkingBudget: 0`。
- Gemini `geminiThinkingBudget: -2` 表示使用思考等级，`-1` 表示自动预算，`0` 表示关闭。
- 一般只调整 temperature 或 Top-P 其中一个。

编辑路由目标时，先选择供应商，模型字段会从该供应商的远程模型端点动态加载。模型列表默认缓存 300 秒，可在供应商配置中调整缓存时间、请求超时和列表上限；“刷新”按钮会绕过缓存。远程列表不可用时仍可手动输入模型名称。

### 图片生成和图片编辑

1. 在 `ImageChannels` 中配置 OpenAI、Grok、Gemini 或 Vertex 生图渠道；Vertex 渠道选择网页中已导入并验证的服务账号凭证。
2. 在 `EditImage.imageChannel` 中选择一个生图渠道。
3. 使用 `#i 提示词` 生图，或引用图片后使用 `#i 提示词` 改图；可在提示词前使用 `grok`、`gpt`、`gemini`、`vertex` 临时切换渠道类型。当前渠道不支持某个参数时，机器人会先提示忽略或调整的内容，再继续生成。
4. 可在 `EditImage.tasks` 中配置自定义图片编辑触发词。

### 经济系统

1. 在 `economy.enable` 开启经济系统。
2. 在 `economy.Groups` 中选择需要启用指令扣费的群。
3. 在 `economy.gamegroups` 中选择启用经济游戏的群。
4. 在 `economy.commandCosts` 中配置各指令的樱花币消耗。

注意：经济游戏如钓鱼、商店、背包等有自己的物品和装备消耗逻辑，不完全依赖指令扣费群。

### Pixiv

1. 在 `pixiv.cookie` 和 `pixiv.refresh_token` 中配置 Pixiv 登录信息。
2. 配置 `r18` 控制 R18 功能可用群。
3. 使用 `#pid`、`#来张插画`、`#日榜` 等指令。

### AI 视频

视频渠道在“图片功能 > 视频渠道管理”中配置：

- `CliProxyMedia.grok`：Grok OpenAI-compatible 媒体网关，可配置多个渠道。
- `CliProxyMedia.gemini`：Gemini Omni Flash Vertex 渠道，凭据从已导入的 Vertex 服务账号中选择。
- `EditImage.videoChannel`：不显式指定渠道时使用的默认视频渠道。

使用 `#v grok <提示词>` 或 `#v gemini <提示词>` 选择渠道；省略渠道参数时使用默认视频渠道。Gemini Omni 当前仅支持 `16:9`/`9:16`、720p 和 3–10 秒视频。不兼容的参数会先提示并自动省略或调整，不会中断生成。

### NovelAI

1. 在 `nai.token` 中填写 NovelAI token。
2. 根据需要调整 `nai.model` 和 `nai.negative`。
3. 使用 `#绘图 提示词`。

### VoxCPM 语音

1. 在 `VoxCPMVoice.roles` 中配置角色名、声音描述和参考音频路径。
2. `defaultRole` 用于普通 `说 内容`。
3. `aiDefaultRole` 用于 AI 工具调用语音。
4. 可用 `#添加语音角色`、`#语音角色列表`、`#删除语音角色` 管理角色。

经济与钓鱼：

- `#签到`、`#我的资产`、`#金币排行`、`#等级排行`。
- `#商店`、`#购买`、`#背包`、`#升级背包`、`#出售`、`#使用`。
- `#领取钓鱼新人礼包`：每个群内玩家限领一次，可领取竹竿、尼龙线和 3 个蚯蚓（已有的基础装备不重复发放）；剩余背包空间不足 5 格时，可发放的物品按商店价折成樱花币。
- `#发红包 金额 个数 [均等|拼手气] [祝福语]`（钓鱼 Lv.5 开放，与转账同一门槛）：总额 10～100000 樱花币、2～20 个，不写模式默认均等，祝福语可省略，模式关键字与祝福语的位置不限。金额与个数都必填且必须紧跟在命令后面，两者写全才会触发——「发红包」「发红包啊」「发红包 1000」都不会有任何反应，闲聊既不会扣钱也不会被机器人接管。发红包当场从余额扣款托管，同一个人最多同时挂 3 个未领完的红包。
- 红包手续费＝`10 + 金额 × 5% ÷ 个数`，在本金之外另收并进入 Bot 账户，播报的金额就是实际发出去的金额。百分比按份数摊薄：份数越少越接近定向转账，价码就越贴近转账的 `10 + 随机 0~10%`；份数多则接近免费。红包至少两份也是同一个理由——单份红包等于一条可指定收款人的免费转账通道。过期只退未领份额，手续费不退。
- 主人发红包不受等级限制，红包里的樱花币一律凭空产生：不扣主人余额、不收手续费、不记支出流水，过期未领完的份额直接作废而非退回。
- `#抢红包`：每人每个红包只能抢一次，且不能抢自己发的。群里有多个红包时按发出顺序先抢最早的那个，抢光后公布明细与手气最佳。红包 5 分钟内有效，超时未领完的份额自动退回发红包的人并在群里通知。
- `#转账`（钓鱼 Lv.5 开放）、`#领取复活币`（无需当日钓鱼；发放 `100 + 2 ×（钓鱼等级 - 1）` 樱花币，余额低于本级发放额时每日可领一次）。
- `#钓鱼`、`#装备鱼竿`、`#装备鱼饵`、`#装备鱼线`。
- 每次抛竿消耗 1 点体力；钓鱼 Lv.1 的初始上限为 10，之后每级上限 +1。未满时每 30 分钟自然恢复 1 点，钓鱼升级会回满当前等级体力。
- 非首领渔获在咬钩提示后 5 秒内收竿，且装备足以通过重量与困难度判定时触发完美收竿；好运护符可替代装备条件。完美收竿令本次经验 ×2，并与适用的其他经验倍率连乘。
- 鱼竿与鱼线都是唯一装备：同一型号最多持有 1 件，不会像鱼饵或道具一样堆叠。
- 鱼竿与鱼线按商店原价的80%出售；鱼竿还会继续乘以当前剩余耐久百分比，鱼线没有耐久折价。
- `#钓鱼状态`（已整合鱼雷与鱼价状态）、`#钓鱼图鉴`（旧命令 `#钓鱼记录` 仍可用）、`#钓鱼攻略`（所有玩家可触发，合并转发 4 张基础攻略图）、`#投放鱼雷`、`#引爆鱼雷 [钓点名]`、`#钓鱼排行`。
- 鱼雷潜伏在投放时的钓点，有两种引爆方式。**每名玩家在每个钓点各能埋一枚未引爆的鱼雷**，六个钓点最多同时潜伏六枚；同一钓点已有自己的雷时不能再埋，换个钓点即可。
- **被别人钓中**：投放后它立刻是陷阱，同钓点的其他玩家钓中就当场炸开，扯断鱼线、对鱼竿造成20点损耗，并令该钓点普通鱼价在35分钟内×1.5，埋雷的人什么也拿不到。
- **自己引爆**：投放满12小时后可发送 `#引爆鱼雷` 自行引爆。不带参数引爆的是自己当前所在钓点的那枚，`#引爆鱼雷 钓点名` 可远程引爆其他钓点的。鱼价加成降为×1.25（能自己挑时机的那一档就该弱一些），另外引爆者独得「爆破收获」——当地随机3条鱼的售价，期望约270樱花币，八成落在130～470之间；余下的成本由35分钟的鱼价加成补回来。
- 爆破收获按固定的中档饵口径摇取（垃圾照常可能摇到，宝藏与噩梦不参与），**不吃任何收益增益**（卡片、鱼饵、天气、职业、完美收竿，以及自己刚炸出的鱼价加成都不作用），也不参与异色判定；但它属于垂钓所得，**亡者抽成印记与高利贷抵债照常结算**。它不算一次抛竿，因此不计入总垂钓、不进图鉴、不给钓鱼经验，也不会让高利贷滚一次利息。
- 两种爆炸共用同一份钓点鱼价加成：同地点重复爆炸只刷新持续时间与倍率，不叠加，其他钓点与首领奖励不受影响。
- 正式消耗体力与鱼饵并抛竿后，无论成功、失败、放弃、超时或钓到鱼雷都累计1次总垂钓；只有成功钓上普通渔获、宝箱、噩梦或首领才累计成功渔获。鱼咬钩后的失败会计入对应图鉴的遭遇次数，等待咬钩阶段超时和鱼雷不会进入鱼类图鉴。
- 捕获过异色个体时，图鉴以“捕获 ×异色数|总捕获数”显示记录，异色数字使用独立颜色；例如异色1条、总计2条显示为“捕获 ×1|2”。尚未捕获异色时仍正常显示“捕获 ×总数”。
- `#钓点`（钓点一览与解锁条件）、`#前往钓点 钓点名`（切换钓点，随钓鱼等级逐步解锁，不同钓点出没的鱼不同，未标注钓点的鱼全地图通用）。解锁顺序只扩展鱼种池，不代表地点难度；渔获阶段由鱼本身的稀有度决定。
- `#钓鱼天气` 与 `#钓鱼状态` 会同时显示当前天气和下一时段天气；限定出没时间、地点与天气可在 `#钓鱼攻略` 中查看，攻略不公开天气概率和倍率。
- 天气作用于装备判定时使用的“有效拉力”，不会改写渔获的真实重量；展示、出售和历史记录均使用真实重量，最终售价只额外结算一次天气价格倍率，避免重量涨价与天气价格重复放大。
- 六档鱼饵使用宽稀有度分布，品质越高整体期望越高，但不会再以 50% 概率锁定单一目标档；高档饵仍可能遇到低价渔获与噩梦。
- 无加成、多云基准下，同档装备与鱼饵的常规一杆强拉成功率约为初始档87%、中间三档90%、毕业档96%；宝藏与噩梦是独立事件，不计入这项成功或失败分母。完整口径与验收数据见[钓鱼基础成功率联合平衡报告](../../docs/fishing-success-balance.md)。
- 五种普通鱼饵按同档装备的每次实际消耗金币期望定价为 8 / 22 / 55 / 131 / 240，实际基础 ROI 从约 30.33% 逐档降至约 0.03%；寻宝鱼饵仍为 333，不参与这条 ROI 曲线。
- 宝藏的基础强度随精品档换算，噩梦随稀有档换算，但两类仍是独立事件且不进入常规一杆成功率分母；天气继续作用于其基础数值。
- 普通鱼与首领均有 1% 概率成为异色个体；异色困难度为普通个体的 1.25 倍，并令最终金币与经验同时 ×4。宝藏、噩梦和鱼雷不参与异色判定。
- 鱼竿熟练度每抛一竿 +1，但折算成控制力时走**对数曲线**：熟练度 1/4/10/20/50/100 分别折算 +1/+5/+10/+15/+24/+32 控制力，上限 +50。前十竿与线性加成基本一致（首领校准仍是熟练度 10 → +10），之后每翻一倍熟练度才多几点——练竿依旧有回报，但不会像线性那样几十竿就把控制力堆过全图困难度、让所有渔获跳过判定。顶级鱼竿的控制力天花板因此是 190 + 50 = 240，永远追不上异色传说/异色首领的 281，那一档只能靠好运护符带走。
- `#钓鱼图鉴 钓点名` 可筛选查看该钓点的图鉴。
- 每个钓点都有一名专属首领。六种宝箱均有 8% 概率开出通用的非卖品「首领鱼饵」；在任意钓点装备后，下一竿均会 100% 呼出当地首领。
- 首领沿用普通渔获的重量判定（好运护符不能跳过），通过后跳过普通难度分支直接进入 60 秒单人首领战。「拉」「溜」与普通精准溜鱼完全使用同一套数值；「攻」可直接发起攻击，冷却 5 秒。必须同时把首领生命和距离降到 0。
- 六名首领统一为困难度 225、重量 170～210、生命 180、攻击 8，仅特殊机制不同。以满体力、满耐久传说之竿和秘银线、平均每秒精准操作一次为无增益/减益基准，模拟胜率随鱼竿控制力加成爬升：加成 +0 约 60%、每 +5 抬约 20 个百分点、+5 约 80%、**+10 起稳定 100%**；换算成对数熟练度即熟练度 0 / 4 / 10。也就是说新买的鱼竿先练十来竿再挑战首领更稳妥，练熟之后首领转为稳定收益；异色首领、鱼竿暗伤与深压等状态另行影响实战难度。
- 每次讨伐基础奖励按个体重量在 600～1000 樱花币间波动、平均约 800，另固定获得 200 钓鱼经验和当前钓点宝箱×1。首领售价只在基础价的 0.75～1.25 倍之间浮动（常规渔获为 0.5～1.5 倍），最低价仍高于传说鱼的基础价上限。除异色令金币与经验 ×4 外，首领不受卡片、怪物诱饵、天气、职业或完美收竿等收益加成；债务等减益在倍率之后正常结算，宝箱仍只发放1个。
- 首领每 5 秒攻击鱼线与鱼竿：鱼线按「承重余量」生成仅限本场的临时耐久（承重×30% + 超出首领体重的富余承重，所以线越勉强、首领越重，缓冲越薄），归零时立即断线并失去当前鱼线；鱼竿损伤永久保存，耐久归零会断裂。六种独立机制分别为绯樱鲤王抽取体力、青柳猿王持续偷钱、雾甲鳄龟冲高张力、赤潮锯鲨皇撕裂鱼线、海沟吞舟兽重创鱼竿、星渊古龙持续回血。限时 60 秒、每 5 秒反击一次，一场最多承受 11 次首领攻击。当前仅支持单人挑战，多人协作暂未开放。
- 赤潮锯刑的鱼线伤害随**当前张力**放大（张力 0/50/85/100 分别为 4/8/11/12 点），顶着高张力抢距离会被锯断鱼线，多花回合「溜」卸力即可规避——首领越重线池越薄，高收益的重量同时也是高风险。
- 探囊鬼手每次命中偷走 **0～50 樱花币**；余额不足 50 时一次掏空，**身无分文则改为每击砸鱼竿 20 点耐久**（传说之竿 10 击即断并永久损失）。一场最多被偷 11×50=550，兜里垫够这个数就绝不会被砸竿——它是唯一必须带着钱来打的首领，胜负都会产生真实损耗。
- 吞舟重撞对鱼竿造成 **3 倍持久伤害**（12 点/击）：满耐久传说之竿 7 击掉 84、打满 11 击掉 132，本场不会被打断，但**耐久不足的鱼竿会当场被撞断并永久损失**（48 点以下第 4 击就断），所以别带着残竿去深渊海沟。同时留下**当场生效的永久暗伤**：前 6 击每击 1 点、第 7 击起每击 2 点，越拖控制力越低；战斗中只提示留下了暗伤，不公布点数与剩余控制力。它是六名中唯一在熟练度 10 也会翻车的首领（约 75%），稳赢门槛为控制力加成 +20，即熟练度 31。
- 每个钓点都有一则当地“怪谈”噩梦；抽到噩梦稀有度后，当地怪谈占 40%，剩余 60% 由其他全部噩梦均分，因此每则地点怪谈也可能在其他钓点出现。
- 通用噩梦会损伤鱼竿、留下难以修复的暗伤、偷取金币或施加 1 层骷髅诅咒；诅咒生效后每次抛竿再累加 1 层，每层令噩梦权重 +1，直到钓到任意噩梦或使用净化圣水。骸骨鲨只造成20点永久暗伤、不损耗耐久，若本次暗伤达到或超过剩余控制力则鱼竿直接断裂。旧装备已经累计的暗伤保持原值。
- 所有噩梦仍会扯断当前鱼线；河神垂青只保住鱼线，深渊猎手的猎魔守护则会消耗1次储存并完整免疫本次断线、伤害、偷取与附加状态。
- 六则怪谈拥有独立机制：溺水花嫁会留下不断加深的印记，使噩梦更容易出现；河童水猴偷走背包中价值最高的鱼饵；雾中捞尸人按当前体力损伤鱼竿并把体力强制变为 1；暮潮幽灵船当场放贷200樱花币并欠下等额高利贷；叩舱潜水钟留下的深压会让之后的垂钓更加吃力；食星之影按物品件数随机吞噬当前鱼竿以外的背包物品，若没有可吞噽物品则损伤鱼竿 20 点耐久。
- 花嫁印记、骷髅诅咒与怪物诱饵都会增加遭遇噩梦的风险；雾灯在这些加权全部结算完之后再把噩梦权重×0.5、宝藏×2、垃圾归零，只降低遭遇率而不是免疫——钓上来的噩梦照常生效。净化圣水会清除花嫁印记、骷髅诅咒、亡者高利贷（含抽成印记）与深压，但不会修复鱼竿上的暗伤。
- 亡者高利贷：欠款未还清前，垂钓所得全额抵债，出售物品的收入不能用来还债；每抛一竿（含空军与噩梦竿）未还清的部分就涨到1.25倍，滚到400即一笔勾销，代价是留下永久抽成印记，此后垂钓所得被抽走10%（即 0.9 倍收益），直到净化圣水洗去。放贷当竿不计息；抵债与抽成都只作用于垂钓所得，出售物品的收入不受影响。
- `#开宝箱 [宝箱名]`：开启钓点专属宝箱。每箱有五种通用奖励（好运护符、修理工具箱、净化圣水、时之沙、首领鱼饵）、当地专属道具、优先补齐未持有种类的随机鱼饵×3、鱼雷×1，以及价值666的当地藏品。只持有一种宝箱时可省略名称；钓获宝箱和开箱奖励都会强制进入背包并允许暂时超出容量，超限期间不能继续购买物品。
- 六种宝箱使用同一权重结构：五种通用奖励各8%、当地专属道具15%、随机鱼饵20%、鱼雷10%、当地藏品15%。时之沙使用后35分钟内将5分钟钓鱼冷却减半为150秒；藏品进入背包后可用 `#出售 藏品名` 变卖。
- 地点专属的限时效果均持续35分钟，但锦鲤许愿签与星愿瓶不设时限：许下之后一直挂着，直到下一次咬钩才兑现并消耗。锦鲤许愿签会被下一次咬钩无条件消耗，仅在钓到垃圾至传说的非首领鱼时将其强制变为异色，宝藏、噩梦、鱼雷和首领仍只消耗不生效。星愿瓶使用格式为 `#使用 星愿瓶 品质`，指定下一次普通咬钩的品质；两种许愿可以同时等待并在同一次咬钩结算。
- 双倍金币卡与怪物诱饵互斥，同一时间只能生效一个：怪物诱饵令金币和经验×3但会拉高噩梦风险，双倍金币卡只令金币×2却没有额外风险，需要二选一。其中一个仍在生效时使用另一个会被拦下，道具不会被消耗，提示中会给出剩余时间。
- `#职业列表`、`#选择职业`、`#进阶职业`。宝藏猎人将宝藏抽取权重提升为1级×1.5、2级×2；钓鱼大师按当前鱼竿熟练度提供无上限鱼线承重（1级×0.25、2级×0.5）；深渊猎手1级最多储存1次完整噩梦免疫并每24小时恢复1次，2级最多储存2次并每12小时恢复1次。充能与下次恢复时间会显示在 `#钓鱼状态` 中。

## 指令扣费

可扣费指令由 `configSchema.js` 的 `commandNames` 定义，默认价格由 `defaultCommandCosts` 定义。当前默认包含：

- 来张涩图、来张萝莉图、来张插画、pid、Pixiv 排行榜和详情。
- AI聊天、AI图片编辑、绘图、Grok 图片、Grok 视频、语音生成、拟态回复。
- 添加词条、删除词条、表情包制作、随机表情包、搜图。

扣费只在 `economy.enable` 开启且当前群在 `economy.Groups` 中时生效。主人不扣费。部分指令支持失败退款。

## 常见问题

### 菜单图片不清晰或过长

菜单使用 Puppeteer 渲染 PNG。`#全部菜单` 会按分类合并转发，一类一张图，避免超长图被 QQ 客户端截断或重复显示。

### 指令没有扣费

检查：

1. `economy.enable` 是否开启。
2. 当前群是否在 `economy.Groups` 中。
3. `economy.commandCosts` 中是否存在该指令名称且价格大于 0。
4. 当前用户是否是主人，主人默认不扣费。

### Pixiv 功能不可用

检查 `pixiv.cookie` 和 `pixiv.refresh_token` 是否有效，R18 功能还需要检查 `r18` 配置。

### Grok 功能不可用

检查 `CliProxyMedia.grok` 渠道中的 `baseURL`、API Key、模型名称和本地媒体网关进程是否可用。

### 生图提示未配置渠道

检查 `ImageChannels` 是否有可用渠道，并在 `EditImage.imageChannel` 中选择对应名称。
