# QQ 群大富翁规则规格

## 1. 游戏定位

这是一个由机器人主持的 2～6 人、严格回合制大富翁。默认使用 40 格环形棋盘、经典版金额体系和两枚六面骰，并采用适合群聊操作的简化看守所。

游戏现金只存在于本局，不读取或修改 Sakura 的用户经济账户。运行时数值以 [`default-40.json`](../plugins/sakura-plugin/resources/monopoly/maps/default-40.json) 为准。

## 2. 默认参数

| 项目 | 默认值 |
| --- | ---: |
| 玩家人数 | 2～6 人 |
| 棋盘 | 40 格环形棋盘 |
| 骰子 | 2 枚六面骰，点数相加移动 |
| 连续对子上限 | 第 3 次对子直接进入看守所 |
| 初始现金 | 1,500 |
| 经过或落在起点 | 领取 200 |
| 完整同色组空地租金 | 基础租金 2 倍 |
| 单块街区建筑上限 | 4 间房，再升级为 1 家旅馆 |
| 银行建筑库存 | 32 间房、12 家旅馆 |
| 建筑出售价格 | 建造价的 50% |
| 地产抵押金额 | 购地价的 50% |
| 赎回金额 | 抵押本金加 10% |
| 掷骰限时 | 60 秒 |
| 购买限时 | 30 秒 |
| 欠款自救限时 | 60 秒 |
| 连续掷骰超时淘汰 | 3 次 |
| 看守所 | 跳过下一次自己的玩家回合 |
| 未开始房间有效期 | 10 分钟 |

## 3. 命令

所有命令都允许带或不带 `#`，例如 `购买` 与 `#购买` 等价。除“创建大富翁”外，这些短语只有在本群已经存在大富翁会话时才会被插件接管；没有会话时处理器直接返回 `false`，不影响其他聊天或插件。

| 命令 | 作用 |
| --- | --- |
| `创建大富翁` | 仅群管理员或白名单用户可创建；一个群同时只能有一局 |
| `加入大富翁` | 加入等待中的房间；创建者也必须自行加入 |
| `退出大富翁` | 开局前退出房间 |
| `开始大富翁` | 房主、管理员或白名单用户开始游戏 |
| `建房 地名` | 掷骰前在指定自有街区建房；兼容 `升级 地名` |
| `卖房 地名` | 掷骰前出售一层建筑；欠款时也可使用 |
| `抵押 地名` | 掷骰前抵押地产；欠款时也可使用 |
| `赎回 地名` | 掷骰前赎回地产 |
| `掷骰` | 完成资产操作后掷骰并移动 |
| `购买` / `放弃` | 处理刚到达的无主地产 |
| `继续结算` | 放弃继续筹款，以现有现金结算欠款 |
| `大富翁状态` | 重新渲染当前完整棋盘 |
| `大富翁规则` | 在棋盘中央显示核心规则 |
| `认输` | 退出当前对局 |
| `结束大富翁` | 仅群管理员或白名单用户可强制结束 |

不提供单独的“查看我的资产”命令；所有玩家资产始终显示在棋盘下方。

## 4. 回合流程

```text
等待加入
  -> 开始
等待掷骰
  -> 可重复建房、卖房、抵押、赎回
  -> 掷两枚骰子，以总点数移动并结算格子
     -> 无主地产：等待购买或放弃
     -> 现金不足：等待卖房、抵押或继续结算
     -> 本次为对子：全部结算完成后由同一玩家再次掷骰
     -> 非对子：进入下一名玩家回合
  -> 同一回合连续第 3 次对子：不移动，直接进入看守所并结束回合
```

资产操作只落在自己的掷骰前阶段，可连续执行多次，不要求棋子站在目标地产上。掷骰后不再开放自由操作；若本回合购买后刚好集齐同色组，要等到自己的下一回合再建房。

每次进入新的玩家回合时，机器人另外发送一条提及该玩家的文字消息。除此之外，正常命令结果、规则、状态和结算都只通过棋盘图片展示。

对子带来的额外掷骰仍属于同一个玩家回合，不增加 `turnSeq`，也不会重复发送回合开始提及；购买决定或欠款自救完成后，才回到再次掷骰阶段。若对子将玩家送入看守所，则不再获得额外掷骰。

## 5. 移动和格子

- 正常移动每次跨过或落在起点时领取 200；开局站在起点不领取。
- 两枚骰子的点数相加作为本次正常移动步数；掷出对子时，在完整处理落地购买、租金和欠款后再掷一次。
- 同一回合连续掷出第 3 次对子时不执行本次移动，玩家直接进入看守所并结束回合。
- 无主地产可以购买；放弃或现金不足时保持无主，不进行拍卖。
- 到达他人未抵押地产时立即支付租金。
- 机会牌可以增减现金、移动、送往监狱，或在玩家之间逐个收付款。
- 城建税为 200，维护费为 100。
- 正常走到监狱格只是探访；“前往监狱”会立即移动并跳过下一次自己的回合，途中不领取起点奖励。
- 自由停车不产生额外奖金或其他效果。
- 一次卡牌移动最多连续解析 4 个格子，防止异常地图产生死循环。

## 6. 地产和租金

### 6.1 购买

玩家只能购买本次移动刚到达的无主地产。支付标价后立即取得所有权；现金等于标价也允许购买。`放弃` 或 30 秒超时均视为放弃，本版本不拍卖。

### 6.2 租金

- 街区使用地图中与当前建筑阶段对应的经典租金。
- 完整持有同色组且整组尚未建房时，空地基础租金翻倍。
- 车站依照同一玩家持有 1～4 座车站，租金为 25 / 50 / 100 / 200。
- 公共设施依照持有 1～2 个，以本次骰点的 4 倍或 10 倍收租。
- 抵押中的地产不收租。

车站和公共设施不是可建房色组，棋盘上也不显示内圈色组线；它们仍保留银行统一计算持有数量所需的内部组关系。

## 7. 建房、卖房和库存

### 7.1 建房

1. 必须完整持有目标街区的同色组。
2. 整个同色组不能有抵押地产。
3. 必须均衡建造：每次只能选择组内建筑数最低的地产。
4. 每条 `建房 地名` 建造一层，可在同一掷骰前阶段连续操作。
5. 每块街区先建 1～4 间房；再建一次时归还 4 间实体房屋并领取 1 家旅馆。
6. 银行房屋或旅馆库存不足时不能建造。
7. 车站和公共设施不能建房。

### 7.2 卖房

1. 每条 `卖房 地名` 只出售一层建筑，返还该层建造价的 50%。
2. 必须反向均衡出售：每次只能从组内建筑数最高的地产拆除。
3. 普通房屋出售后归还银行库存。
4. 旅馆出售时降为 4 间房、旅馆归还银行；如果银行不足 4 间房，暂时不能降级旅馆。
5. 本版本不允许把空地直接卖回银行。

## 8. 抵押和赎回

- 没有建筑的自有地产可以抵押，银行支付地图标注的抵押金额，即购地价的 50%。
- 抵押街区前，必须先卖掉该同色组的所有房屋和旅馆。
- 抵押后仍保留所有权，但不收租，也不能在其同色组继续建房。
- 掷骰前可发送 `赎回 地名`，支付抵押本金加 10% 利息；小数金额向上取整。
- 欠款阶段只开放卖房和抵押，不开放建房或赎回。

## 9. 欠款、自救和破产

所有现金始终为非负整数。

1. 现金足够时立即足额支付。
2. 现金不足时暂停当前结算，棋盘中央显示应付金额、缺口和可用命令，并进入 60 秒自救期。
3. 只有欠款玩家可以通过 `卖房 地名` 和 `抵押 地名` 筹款；每次操作都会保存状态并单独刷新棋盘。
4. 现金达到应付金额后自动付款，并继续剩余结算或进入下一回合。
5. 玩家也可以发送 `继续结算`，或等待自救期超时，以现有全部现金强制结算。
6. 若仍不足，收款方只获得实际支付金额，欠款玩家破产，剩余地产和建筑归还银行。
7. 一张机会牌涉及多人付款时，依照行动顺序逐笔处理；任一笔欠款都可以暂停并进入自救期。

由于本版本暂不实现玩家交易和拍卖，破产资产不会转让或拍卖给其他玩家。

## 10. 超时、持久化和并发

- 第 1、2 次掷骰超时会自动掷两枚骰子；自动到达无主地产时直接放弃购买，若掷出对子则完成结算后仍保留额外掷骰。
- 连续第 3 次掷骰超时按认输处理；一次主动有效掷骰会清零计数。
- 购买超时等同于 `放弃`。
- 欠款超时等同于以现有现金执行 `继续结算`。
- 每次状态变化先持久化，再发送图片。
- 会话保存绝对截止时间；机器人重启后会恢复或补执行超时。
- 超时令牌包含会话、回合序号、阶段和截止时间，旧任务不能重复结算新状态。

## 11. 结束和排名

游戏没有轮数上限；仅剩一名在场玩家时自然结束。管理员或白名单用户强制结束时不计算胜者。

```text
净资产 = 现金
       + 未抵押地产购地价
       + 未抵押地产上的全部建造成本
       + 已抵押地产的抵押价值
```

仍在场玩家排在已破产或认输玩家之前。净资产相同依次比较现金、地产数量；仍相同时由服务端自动掷骰决定顺序。最终名次显示在棋盘下方的净资产排名面板中。

## 12. 图片和消息规则

- 每个有效命令都实时渲染一张最新棋盘，并把图片作为单独一条群消息发送。
- 有当前会话时，规则错误也写入棋盘中央信息区，不另发普通结算文字。
- 只有新玩家回合开始时，才在图片之后另发一条提及下一名玩家的文字消息。
- 棋盘中央最上方显示当前玩家颜色和阶段；下方依次显示双骰与总点数、移动起终点、购买地点和价格、无 `#` 的购买/放弃按钮、拆分成多张卡的当前玩家资产，以及分开的银行房屋和旅馆库存。
- 非购买阶段会把购买区替换为当前有用的结算状态和可用命令，不保留标题、副标题或说明性页脚。
- 未购买格统一为白色；购买后按玩家颜色淡染，并在外圈显示占领者横条。
- 只有街区显示靠近棋盘内圈的色组线，车站和公共设施不显示。
- 地名最多 4 个字，金额使用同字号置于下一行；玩家棋子位于金额下方，同格多人时横向并排。
- 本回合移动起点失焦，灰色起点和虚线箭头完整连接到深色描边的终点。
- 棋盘下方固定为纵向净资产排名，只显示名次、红色/蓝色/绿色等棋子颜色名、净资产和当前现金，不展示 QQ 昵称。

## 13. 本阶段明确不做

- 玩家发起交易、赠与或换地；
- 无主地产或破产资产拍卖；
- 偷地卡、强换卡、绝地反击卡、拒绝卡等道具；
- 局外金币、排行榜或奖励；
- 玩家上传脚本或自定义地图。
