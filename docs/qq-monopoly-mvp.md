# QQ 群大富翁规则规格

## 1. 游戏定位

这是一个由机器人主持的 2～6 人、严格回合制大富翁。默认使用 40 格环形棋盘、经典版金额体系和两枚六面骰，看守所沿用经典规则（掷对子出狱、保释金、三次机会上限）。

游戏现金只存在于本局，不读取或修改 Sakura 的用户经济账户。运行时数值以 [`default-40.json`](../plugins/sakura-plugin/resources/monopoly/maps/default-40.json) 为准。

## 3. 命令

所有命令都允许带或不带 `#`，例如 `购买` 与 `#购买` 等价。除“创建大富翁”和“大富翁规则”外，这些短语只有在本群已经存在大富翁会话时才会被插件接管；没有会话时处理器直接返回 `false`，不影响其他聊天或插件。

| 命令 | 作用 |
| --- | --- |
| `创建大富翁` | 仅群管理员或白名单用户可创建；一个群同时只能有一局 |
| `加入大富翁` | 加入等待中的房间；创建者也必须自行加入 |
| `退出大富翁` | 开局前退出房间 |
| `开始大富翁` | 房主、管理员或白名单用户开始游戏 |
| `建房 地名` | 掷骰前在指定自有街区建房；兼容 `升级 地名` |
| `卖房 地名` | 掷骰前出售一层建筑；欠款时也可使用 |
| `抵押 地名` | 掷骰前抵押地产；欠款时也可使用 |
| `赎回 地名` | 掷骰前赎回地产 |
| `收购 地名` | 掷骰前按双倍标价强制买下关键地，详见 §8.1；兼容 `强制收购 地名` |
| `r` | 掷骰并移动；兼容 `扔`、`扔骰子`、`扔色子` |
| `保释` | 在看守所时掷骰前出狱：有保释令用卡，否则付 50；兼容 `赎身`、`交保释金` |
| `购买` / `放弃` | 处理刚到达的无主地产；兼容 `y` / `n` |
| `使用 道具名 [参数]` | 掷骰前使用道具，参数为地产名或目标玩家（可直接 @） |
| `否决` / `不管` | 在否决窗口内让对方道具作废，或放行 |
| `出价 金额` | **仅私聊**，暗拍期间报价；兼容 `报价 金额`。群里发不算数 |
| `强制结算` | 放弃继续筹款，自动变现后以现有现金结算欠款 |
| `大富翁规则` | 渲染一张完整规则长图；**不需要本群有对局**，私聊也能查；兼容 `大富翁帮助` |
| `大富翁棋盘` | 刷新一张当前棋盘；兼容 `查看棋盘`、`刷新棋盘` |
| `认输` | 退出当前对局 |
| `结束大富翁` | 仅群管理员或白名单用户可强制结束 |

不提供单独的“查看我的资产”命令；所有玩家资产始终显示在棋盘下方，`大富翁棋盘` 会刷新一张完整棋盘。

`大富翁规则` 是唯一不依赖对局的命令：它渲染的是一张与对局状态无关的规则长图（[`RulesRenderer.js`](../plugins/sakura-plugin/lib/monopoly/presentation/RulesRenderer.js)），全部数值、道具、色组和租金表都从地图读取，改地图就自动同步。图只跟地图有关，因此渲染一次后缓存到插件重载为止。

局内命令只有本局在场玩家发送才会被接管，破产和认输的玩家与路人一样被静默放行。同一个用户同时只能参与一局大富翁，不能在两个群里各开一局。`使用 xx` 与经济系统同形，道具名不属于本局时会原样交还给经济系统处理。

## 4. 回合流程

```text
等待加入
  -> 开始
等待掷骰
  -> 可重复建房、卖房、抵押、赎回、使用道具
     -> 道具目标持有否决令：进入等待否决，逐层翻转后回到本人回合
  -> 在看守所时可先发送 保释 直接出狱
  -> 掷两枚骰子，以总点数移动并结算格子
     -> 在看守所：对子当场出狱并前进，未中则消耗一次机会并结束回合
     -> 无主地产：等待购买或放弃
     -> 现金不足：等待卖房、抵押或强制结算
     -> 本次为对子：全部结算完成后由同一玩家再次掷骰
     -> 非对子：进入下一名玩家回合
  -> 同一回合连续第 3 次对子：不移动，直接进入看守所并结束回合
```

资产操作和道具只落在自己的掷骰前阶段，可连续执行多次，不要求棋子站在目标地产上。掷骰后不再开放自由操作；若本回合购买后刚好集齐同色组，要等到自己的下一回合再建房。在看守所里同样保留这一整套掷骰前操作。

掷完骰会先给掷骰的人单发一条提及回执（点数、落点、本次结算摘要、现金与待办），再给接棒的玩家发一条回合提示；两者恰好是同一个人时合并成一条。其余命令结果、规则和结算仍以棋盘图片为主。

对子带来的额外掷骰仍属于同一个玩家回合，不增加 `turnSeq`，也不会重复发送回合开始提及；购买决定或欠款自救完成后，才回到再次掷骰阶段。若对子将玩家送入看守所，则不再获得额外掷骰。

## 5. 移动和格子

- 正常移动每次跨过或落在起点时领取 200；开局站在起点不领取。
- 两枚骰子的点数相加作为本次正常移动步数；掷出对子时，在完整处理落地购买、租金和欠款后再掷一次。
- 同一回合连续掷出第 3 次对子时不执行本次移动，玩家直接进入看守所并结束回合。
- 无主地产可以购买；放弃或现金不足时保持无主，不进行拍卖。
- 到达他人未抵押地产时立即支付租金。
- 棋盘上有“机会”和“命运”两个牌堆，各自独立洗牌，抽完自动重洗。两堆各 17 张：各有 16 种卡面，其中机会的“末班列车”和命运的“否决令”各放 2 份（地图里靠卡面的 `count` 字段配置，洗牌按多重集展开）。
- 卡牌可以增减现金、移动、送往看守所、按建筑数量征收维修费、在玩家之间逐个收付款，或发放道具。
- 指定前往最近车站或公共设施的卡牌，该次租金按 2 倍支付。
- 城建税为 200，维护费为 100。
- 正常走到监狱格只是探访；“前往监狱”会立即移动进入看守所，途中不领取起点奖励。
- 在看守所里照常轮到自己：掷出对子当场出狱并按点数前进（不再追加掷骰），未中则消耗一次机会；也可以在掷骰前用保释令或付 50 保释金直接出狱。三次都没掷出对子时强制赎身，有保释令优先顶掉罚金，付不起罚金则进入欠款流程。
- 在看守所期间仍可建房、卖房、抵押、赎回和使用道具。
- 自由停车不产生额外奖金或其他效果。
- 一次卡牌移动最多连续解析 4 个格子，防止异常地图产生死循环。

## 6. 地产和租金

### 6.1 购买

玩家只能购买本次移动刚到达的无主地产。支付标价后立即取得所有权；现金等于标价也允许购买。`放弃` 或 30 秒超时均视为放弃，本版本不拍卖。

### 6.2 租金

- 街区使用地图中与当前建筑阶段对应的经典租金。
- 完整持有同色组时，该组内**仍是空地**的地产基础租金翻倍。这是按地块单独判定的：组内别的地已经建了房，剩下的空地照样按 2 倍收租。
- 车站依照同一玩家持有 1～4 座车站，租金为 25 / 50 / 100 / 200。
- 公共设施依照持有 1～2 个，以本次骰点的 4 倍或 10 倍收租。
- 抵押中的地产自身不收租，但仍计入同色组是否齐全，以及车站和公共设施的持有数量；也就是组内有地被抵押时，其余未抵押空地照样按 2 倍收租。这与官方规则一致。

车站和公共设施不是可建房色组，棋盘上也不显示内圈色组线；它们仍保留银行统一计算持有数量所需的内部组关系。

## 7. 建房、卖房和库存

### 7.1 建房

1. 必须完整持有目标街区的同色组。
2. 整个同色组不能有抵押地产。
3. 必须均衡建造：每次只能选择组内建筑数最低的地产。
4. 每条 `建房 地名` 建造一层，可在同一掷骰前阶段连续操作。
5. 每块街区先建 1～4 间房；再建一次时归还 4 间实体房屋并领取 1 家旅馆。
6. 银行房屋或旅馆库存不足时不能建造。
7. 车站和公共设施不能建房。

### 7.2 卖房

1. 每条 `卖房 地名` 只出售一层建筑，返还该层建造价的 50%。
2. 必须反向均衡出售：每次只能从组内建筑数最高的地产拆除。
3. 普通房屋出售后归还银行库存。
4. 旅馆出售时降为 4 间房、旅馆归还银行；如果银行不足 4 间房，暂时不能降级旅馆。
5. 本版本不允许把空地直接卖回银行。

## 8. 抵押和赎回

- 没有建筑的自有地产可以抵押，银行支付地图标注的抵押金额，即购地价的 50%。
- 抵押街区前，必须先卖掉该同色组的所有房屋和旅馆。
- 抵押后仍保留所有权，但不收租，也不能在其同色组继续建房。
- 掷骰前可发送 `赎回 地名`，支付抵押本金加 10% 利息；小数金额向上取整。
- 欠款阶段只开放卖房和抵押，不开放建房或赎回。

### 8.1 强制收购

这是常驻规则，不需要卡牌。掷骰前发送 `收购 地名`：

1. 目标必须是**别人名下、没有建筑**的地产；
2. 目标必须是**关键地**——买下它之后你正好凑成一个完整色组，否则不允许收购；
3. 成交价为**标价的两倍**，全额给原主；
4. 每人整局只能用 **3 次**，打出即算用掉，被否决令挡下也不退还；
5. 可以被否决令否决。

**抵押地怎么算**：成交额里先替银行清偿抵押（本金 + 一成利息），余额归原主，地契解除抵押后过户。这样抵押与否不改变这笔买卖的性价比，抵押也就当不成免疫。例如樱都城堡（标价 400 / 抵押 200）双倍成交 800：220 清偿抵押、580 归原主、买家拿到一张干净地契。

**关于防御**：规则上有建筑的地不能被收购，但被盯上的人手里只剩这一块、凑不齐色组，因此**建不了房**——建房防御在这个机制下不成立。目前被收购方唯一的防御手段是否决令。（只有一种残留情况例外：他曾拥有整组并建过房，组被拆散后这块的建筑还在。）

`强制征收` 道具是本规则的**原价特权版**，共用抵押清偿逻辑和「别人名下、没有建筑」这两条限制，但另外三点都更宽松：只付**一倍**标价，不受**关键地**限制（不需要凑成完整色组，任意一块都能征收），也不占用每局 3 次的额度。它同样可以被否决令挡下。

## 9. 道具和否决

道具只能由机会或命运牌发放，不能购买或交易，持有数量没有上限——每种道具在牌堆里的份数本身就是上限。破产和认输时背包全部作废，不随地产转给债主。

| 道具 | 牌堆份数 | 说明 |
| --- | ---: | --- |
| 保释令 | 机会 1、命运 1 | 在看守所发送 `保释` 免费出狱；三次机会用尽时自动顶掉保释金 |
| 否决令 | 命运 2 | 让一次针对自己的道具作废，也能否决别人的否决 |
| 地契置换 | 机会 1 | 与任意玩家交换一块没有建筑的地 |
| 强制征收 | 机会 1 | 强制收购的原价版：只付一倍标价，不限关键地，且不占每局 3 次额度 |
| 拆迁令 | 机会 1 | 拆掉对方等级最高的一栋建筑，对方得不到任何补偿 |
| 拍卖令 | 机会 1 | 把任意一块没有建筑的地挂上暗拍，详见 §9.1 |
| 税务稽查 | 命运 1 | 指定一名玩家按净资产的一成向银行补税，钱不进使用者口袋 |

- 主动道具只能在自己掷骰前使用，目标玩家可以 @、写 QQ 号或写棋子颜色名。
- 主动道具对任何在场玩家都可以使用，不限制对方的净资产高低。
- 道具表里的「强制收购」是常驻规则的名字来源，不会作为卡牌发放，见 §8.1。
- 交换和征收的目标地块不能有建筑；接手抵押中的地契要当场向银行支付一成过户利息。
- 拆迁令在对方多块建筑并列最高时随机选一块；拆旅馆需要银行拿得出 4 间房。
- 打出主动道具后，只有当目标手上确实有否决令时才会开启 15 秒否决窗口，否则直接结算。否决链每加一层翻转一次结果：偶数层生效，奇数层作废。窗口超时视为不否决。
- 否决链结算完毕后回合仍归使用者，不换人。
- 道具引发的欠款（例如补税付不起）结算完后，回合同样还给使用者，他还没掷骰。

### 9.1 暗拍

拍卖令的标的可以是**任意一块没有建筑的地**：无主地、别人的地，甚至自己的地。

1. 打出后进入 `暗拍进行中` 阶段，全场暂停 45 秒，群里公告标的、归属和底价。
2. **底价为该地产的抵押价**（约售价一半）。
3. 所有在场玩家**私聊**机器人发送 `出价 金额` 参与，出价互相保密，机器人只回执给出价人自己。
4. 出价不得低于底价，也不得超过自己的现金；截止前可以重复发送修改，以最后一次为准。
5. 截止后开标，价高者得；**平价时先报价的人胜**。群里只公布中标者和成交价，其他人的出价不公开。
6. 成交款：拍走**别人的地**时全额给原主，无主地则归银行。
7. **原主也可以出价保住自己的地**，但中标时这笔钱要交给**银行**——白留会让人人报天价，机制就废了。
8. 接手抵押中的地产，中标者要另向银行补一成过户利息。
9. 无人出价则流拍，地保持原状。
10. 暗拍期间掷骰和一切资产操作都被挡住，所以开标时每个人的现金和出价时完全一致。

## 10. 欠款、自救和破产

所有现金始终为非负整数。

1. 现金足够时立即足额支付。
2. 现金不足时暂停当前结算，棋盘中央显示应付金额、缺口和可用命令，并进入 60 秒自救期。
3. 只有欠款玩家可以通过 `卖房 地名` 和 `抵押 地名` 筹款；每次操作都会保存状态并单独刷新棋盘。
4. 现金达到应付金额后自动付款，并继续剩余结算或进入下一回合。
5. 玩家也可以发送 `强制结算`，或等待自救期超时；两者等价。
6. 强制结算会先自动变现：优先抵押所有没有建筑的地（抵押不改变净资产），仍不够才拆建筑（只退半价，净资产实打实减少）；同类候选按“每换一块钱损失多少租金”从小到大挑。
7. 变现后仍不足即破产：收款方只拿到实际支付金额。
8. 一张卡牌涉及多人付款时，依照行动顺序逐笔处理；任一笔欠款都可以暂停并进入自救期。

破产清算按债主区分：

- 欠**玩家**：建筑先折回银行库存，空地连同抵押状态过户给债主；债主要为每块接手的抵押地立刻向银行支付一成利息，现金不足时只扣到见底，不会把债主也拖进欠款流程。
- 欠**银行**：建筑折回库存，地产全部变回无主。
- 两种情况下破产玩家的现金清零、背包道具一律作废。

主动 `认输` 与破产不同：现金清零、道具作废，名下地产**一律归还银行**，不转给任何人。

本版本仍不实现玩家之间自由谈判的交易。地产易主只可能通过破产清算、强制收购（§8.1）、暗拍（§9.1）或道具发生。

## 11. 超时、持久化和并发

- 第 1、2 次掷骰超时会自动掷两枚骰子；自动到达无主地产时直接放弃购买，若掷出对子则完成结算后仍保留额外掷骰。
- 连续第 3 次掷骰超时按认输处理；一次主动有效掷骰会清零计数。
- 购买超时等同于 `放弃`。
- 欠款超时等同于 `强制结算`，同样会先自动变现。
- 否决超时等同于 `不管`，道具照常生效。
- 暗拍到点即开标，不延时、不加价轮。
- 掷骰前被插曲打断（否决窗口、暗拍、道具引发的欠款）时，结算完回到等待掷骰会**重新给满 60 秒**，不保留也不折算打断前的剩余时间。建房、卖房、抵押、赎回和保释则**不重置**这个时限，回合的掷骰倒计时照常走。
- 等待加入超过 10 分钟房间自动解散。
- 每次状态变化先持久化，再发送图片；同一群的并发操作由会话锁串行化。
- 会话保存绝对截止时间；机器人重启后会恢复或补执行超时。
- 超时令牌包含会话、回合序号、阶段和截止时间，旧任务不能重复结算新状态。

## 12. 结束和排名

游戏没有轮数上限；仅剩一名在场玩家时自然结束。管理员或白名单用户强制结束时不计算胜者。

```text
净资产 = 现金
       + 未抵押地产购地价
       + 未抵押地产上的全部建造成本
       + 已抵押地产的抵押价值
```

仍在场玩家排在已破产或认输玩家之前。净资产相同依次比较现金、地产数量；仍相同时由服务端自动掷骰决定顺序。最终名次显示在棋盘下方的净资产排名面板中。

## 13. 图片和消息规则

- 改变了盘面的命令都会实时渲染一张最新棋盘，并把图片作为单独一条群消息发送。
- `大富翁规则` 的长图较大，发送前先 `e.react(124)` 贴个表情回执，和钓鱼攻略、画像两条耗时指令保持一致。
- 不改变盘面的帧只回文字：放弃购买、超时放弃、开启否决窗口、道具被否决都不重复出图，相关信息写进那条文字里。
- 有当前会话时，规则错误也写入棋盘中央信息区，不另发普通结算文字。
- 图片之后按顺序补文字：先是掷骰人的结算回执，再是下一名玩家的回合提示；收件人相同则合并。任一条发送失败只记日志，不会连累其余消息。
- 棋盘中央最上方显示当前玩家颜色和阶段；下方依次显示双骰与总点数、移动起终点、购买地点和价格、无 `#` 的购买/放弃按钮、拆分成多张卡的当前玩家资产，以及分开的银行房屋和旅馆库存。
- 非购买阶段会把购买区替换为当前有用的结算状态和可用命令，不保留标题、副标题或说明性页脚。
- 未购买格统一为白色；购买后按玩家颜色淡染，并在外圈显示占领者横条。
- 只有街区显示靠近棋盘内圈的色组线，车站和公共设施不显示。
- 地名最多 4 个字，金额使用同字号置于下一行；玩家棋子位于金额下方，同格多人时横向并排。
- 本回合移动起点失焦，灰色起点和虚线箭头完整连接到深色描边的终点。
- 棋盘下方固定为纵向净资产排名，只显示名次、红色/蓝色/绿色等棋子颜色名、净资产和当前现金，不展示 QQ 昵称。

## 14. 本阶段明确不做

- 玩家之间自由发起的交易、赠与或换地（换地只能通过地契置换道具触发）；
- 无主地产或破产资产拍卖；
- 局外金币、排行榜或奖励；
- 玩家上传脚本或自定义地图。
