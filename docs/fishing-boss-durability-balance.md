# 首领耐久平衡报告

2026-09-26，熟练度20全胜验收修订版。本报告及同名JSON覆盖此前版本。以下为本地模拟结果，未进行线上玩家测试。

## 共同基准

**硬性验收目标：满耐久传说竿＋秘银线、熟练度20、每秒按既定拉/溜/攻策略操作，六名普通首领必须全胜。**常规验收与边界验收任一场失败均判定不通过。

本轮在用户批准的210～215范围内采用215。原225基准在控制力200、压力接近25时几乎没有竿损余量；215允许最多10点战中竿损，最大合法压力下仍保留基础拉距。

六名首领基础困难度统一为 **215**，由配置校验保证一致。生命180、攻击属性8、重量170～210、60秒限时、玩家攻冷却4秒、首领反击间隔5秒及奖励沿用上一轮。

鱼竿实际控制力 = （基础控制力 × 剩余耐久 / 最大耐久 + floor(熟练度 / 2)）× 深压倍率。

玩家「攻」的伤害 = max(6, floor(实时控制力 / 6) + 5 + 随机整数0～4)。

控制力190时为36～40伤害，控制力200时为38～42。普通反击竿损为max(1, ceil(攻击/4))，攻击8时损2点。耐久损失仍即时降低控制力和玩家伤害。

## 鱼线规则

- 移除本场鱼线耐久、首领累计线损、耐久归零断线及相关状态显示。
- 鱼线承重仍用于收竿重量判定，超过承重仍按原概率判断，超过两倍承重仍会断线；好运护符不能绕过首领重量判定。超重对鱼竿的原有影响保留。
- 战斗中张力达到100仍会断线，玩家拉距或首领反击推高张力均会触发。
- 河神保线、噩梦与鱼雷直接断线等既有事件规则保留；河神在首领反击导致张力崩断时仍保线并补偿，本次挑战仍失败。
- 临时耐久原本只存在于会话中，无需新增玩家数据库迁移。

## 其他已落实机制

- 雾中捞尸人成功结算时增加1层持久致盲；后续首次有效收竿命中率为0.9^层数。每竿只判定一次，重复消息与拉/溜/攻不重抽。空钩结束本次钓鱼，保留正常消耗，不退鱼饵、不发渔获奖励、不额外损伤竿线。首领鱼饵和好运护符也不能跳过。
- 骸骨鲨扣最大鱼竿耐久的20%，向上取整；不减少最大耐久，耗尽即断竿。传说竿扣38，星穹竿扣190。
- 通用噩梦断线保留；深渊猎手完整免疫时不受本次断线或附加状态影响。
- 净化圣水清除全部致盲，换鱼饵、换装备及工具箱不清除。工具箱修满耐久并清除深压。
- 旧暗伤直接丢弃，启动迁移删除旧列并补齐致盲字段，不把暗伤折算成新耐久损失。

## 模拟前提

- 固定种子0x5a17，每名首领、每种场景10000次；共17种场景，最终模拟 **1020000场**。
- 秘银线承重210；传说竿基础控制力190、最大耐久190；星穹竿控制力190、最大耐久950。
- 无职业承重、天气、深压或河神等额外状态；初始余额1000，足以覆盖猿王偷取。所有表格均以通过致盲收竿判定、进入挑战为前提。
- 每场重新抽重量、0～25压力和鱼的状态轮换。默认第1秒起每秒操作一次；每2秒场景从第2秒起操作。
- 冷却结束优先攻，其余动作根据距离和张力选择拉/溜。鲤王反击前可尝试拉入低伤距离区间。锯鲨反击前，如果攻未就绪且卸力能跨过竿损档位，则优先溜；遇到致命反击可推迟攻。另列通用打法对照。
- 同时发生的事件按状态轮换、首领反击、玩家动作顺序执行。首领生命归零后反击停止，玩家仍须拉到距离0。
- 耐久初值向下取整；95%耐久场景实际为180/190，约94.7%；其他列出的比例均对应整数耐久。
- 不模拟QQ延迟、误操作和消息发送耗时引起的计时器顺延，不声称采用最优策略。10000场全胜只代表该组样本。

## 全胜边界验收

常规目标条件下，六名首领各10000场全部通关。另外验证以下有限边界集合：

- 鱼重固定最大210，压力固定为运行时最大值（略低于25）。
- 玩家伤害分别固定为每击最低值和最高值；猿王每次偷取固定为最大值，初始余额1000。
- 状态选择覆盖七次轮换的128种选择序列。
- 状态时长分别固定为8000、8001、9000、9999、10000、10001、11000、11999、12000毫秒，覆盖动作与反击附近的时间边界。

## 结果解释与限制

- 目标条件熟练20胜率为100%，通用打法对照也为100%。零熟练约64%～76%，熟练10约83%～96%；熟练40与80样本同样全部通关。
- 本轮保留已确定的六个首领机制与反击数值；没有取消反击来换取全胜。
- 熟练20平均胜局耗时约20.3～22.3秒，平均竿损6～8.9点；边界场景最慢44秒，仍在60秒限时内。
- 拉距硬门槛保留：max(0, 困难度−实际控制力)+压力≥50时基础拉距为0。满传说竿、熟练20初始控制力200，损失10耐久后为190；215−190+压力仍小于50。
- 满耐久是全胜条件的一部分。熟练20、180/190耐久相当于满耐久零熟练；熟练20、90%耐久约22%～37%，80%耐久样本未通关。
- 90%耐久、熟练40约68%～80%；80%耐久、熟练80约72%～85%。零熟练满星穹竿约93%～95%。
- 每2秒操作、熟练20约96%～99%，不属于每秒操作的全胜条件。
- 异色困难度为round(215×1.25)=269；熟练80异色约14%～26%，熟练120与160样本全部通关。普通首领与异色分别列示。
- 本次目标场景无额外减益，余额足以覆盖猿王偷取。致盲仍单独影响收竿：整竿成功率=战斗胜率×0.9^层数。
- 模拟不读写真实玩家数据，不启动或重启机器人，不发送QQ消息。
